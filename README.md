# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

### Текущий этап разработки:
##### feature/admin-panel

#### Цель

Улучшение административной панели Django для удобного управления пользователями, заявками и комментариями.

#### Выполненные задачи

#### Пользователи

- настроено отображение пользователей в административной панели;
- добавлены фильтры по ролям и активности;
- реализован поиск по логину, электронной почте и имени пользователя;
- настроена сортировка списка пользователей.

#### Заявки

- улучшено отображение списка заявок;
- добавлены фильтры по:
  - статусу;
  - приоритету;
  - категории;
  - автору;
  - исполнителю;
  - дате создания;
- реализован поиск по теме, описанию, автору и исполнителю;
- добавлена навигация по дате создания (`date_hierarchy`);
- настроена сортировка по дате создания.

#### Комментарии

- улучшено отображение комментариев;
- реализованы фильтры и поиск;
- добавлена сортировка по дате создания.

#### Inline-комментарии

- реализовано отображение комментариев непосредственно внутри карточки заявки;
- комментарии доступны для просмотра и редактирования без перехода в отдельный раздел административной панели.

#### Массовые действия (Admin Actions)

Добавлены административные действия:

- перевод выбранных заявок в статус «В работе»;
- перевод выбранных заявок в статус «Ожидает уточнения»;
- перевод выбранных заявок в статус «Выполнена»;
- закрытие выбранных заявок.

#### Возможности дальнейшего развития

Административная панель может быть расширена следующими возможностями:

- цветовая индикация статусов и приоритетов;
- отображение количества комментариев у заявки;
- экспорт списка заявок в Excel и CSV;
- массовое назначение исполнителя;
- автоматическая отправка уведомлений при выполнении массовых действий;
- отображение пользовательских метрик и аналитики непосредственно в административной панели.

#### Результат

Административная панель стала удобным инструментом управления информационной системой технической поддержки. Реализованы поиск, фильтрация, массовые операции и встроенное отображение связанных комментариев, что значительно упрощает сопровождение системы.

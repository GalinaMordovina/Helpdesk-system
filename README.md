# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

### Текущий этап разработки:
#### feature/web-comments

#### Что реализовано

В рамках данной ветки реализована работа с комментариями и расширено редактирование заявок через веб-интерфейс.

#### Комментарии

- просмотр комментариев на странице заявки;
- отображение формы добавления комментария;
- создание комментария авторизованным пользователем;
- привязка комментария к заявке и автору;
- защита от создания пустых комментариев;
- отображение ошибок валидации без перехода на отдельную страницу.

#### Редактирование заявок

Добавлено разделение форм редактирования в зависимости от роли пользователя.

Обычный пользователь может изменять:

- тему;
- описание;
- категорию;
- приоритет.

Специалист технической поддержки и руководитель дополнительно могут изменять:

- статус заявки;
- исполнителя.

Для этого реализованы две отдельные формы:

- `TicketForm` - создание заявки и редактирование пользователем;
- `TicketUpdateForm` - редактирование заявки специалистом поддержки и руководителем.

#### Ограничение прав

Реализовано разграничение доступа:

- пользователь не может изменить статус заявки;
- пользователь не может изменить исполнителя;
- специалист поддержки и руководитель имеют доступ к служебным полям.

#### Тестирование

Добавлены тесты, проверяющие:

- отображение комментариев;
- отображение формы комментариев;
- создание комментариев;
- запрет создания пустого комментария;
- доступ только авторизованным пользователям;
- привязку комментария к заявке;
- отсутствие поля статуса у обычного пользователя;
- отображение поля статуса у специалиста поддержки;
- отображение поля статуса у руководителя;
- невозможность изменения статуса обычным пользователем;
- возможность изменения статуса специалистом поддержки.

Все тесты успешно пройдены.

# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

### Текущий этап разработки:
##### feature/email-notifications

#### Цель

Реализация подсистемы email-уведомлений для информационной системы управления заявками технической поддержки.

#### Выполненные задачи

- создано приложение `notifications`;
- настроена отправка электронной почты через SMTP Gmail;
- вынесена логика отправки писем в отдельный сервис (`notifications/services.py`);
- реализована отправка тестового email-уведомления;
- реализлено автоматическое уведомление при создании новой заявки;
- проверена работа SMTP на реальной электронной почте;
- выполнено тестирование через Django Shell и Postman;
- архитектура подсистемы уведомлений подготовлена для дальнейшего расширения.

#### Подготовлено для следующих этапов

Архитектура подсистемы позволяет без изменения существующей логики добавить:

- уведомления о назначении исполнителя;
- уведомления об изменении статуса заявки;
- уведомления о закрытии заявки;
- HTML-шаблоны писем;
- интеграцию с другими каналами уведомлений (Telegram, SMS и др.).

#### Результат

В системе реализована подсистема email-уведомлений, обеспечивающая автоматическую отправку писем при наступлении событий жизненного цикла заявки. Логика уведомлений вынесена в отдельный сервис, что делает систему расширяемой и соответствует принципам модульной архитектуры.

# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

#### Технологический стек
- Backend
- Python 3.12
- Django
- Django REST Framework
- PostgreSQL

### Текущий этап разработки:
##### feature/comments-app

#### Цель

Реализация механизма комментариев для заявок технической поддержки.

#### Выполненные задачи

* создано приложение `comments`;
* реализована модель `Comment`;
* настроена связь комментария с заявкой (`Ticket`);
* настроена связь комментария с пользователем (`User`);
* добавлены поля даты создания и изменения комментария;
* выполнены миграции базы данных;
* настроена административная панель Django для работы с комментариями.

#### Результат

В системе реализована возможность хранения комментариев к заявкам. Комментарии позволяют фиксировать ход обработки заявки, уточнения пользователя и результаты работы специалиста технической поддержки.

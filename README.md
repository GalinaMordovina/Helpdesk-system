# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

### Текущий этап разработки:
##### feature/roles-refactor

#### Реализовано

- переработана модель ролей пользователей;
- роли приведены в соответствие с бизнес-процессом:
  - Employee;
  - Support;
  - Manager;
- обновлена логика работы системы уведомлений;
- реализована автоматическая отправка email в зависимости от текущего статуса заявки;
- уведомления о новых заявках, ожидании уточнения и завершении работ направляются всем менеджерам;
- уведомления о назначении заявки направляются назначенному специалисту;
- уведомления о закрытии заявки направляются автору обращения;
- реализована единая функция отправки email и единый шаблон формирования текста уведомлений.

#### Дальнейшее развитие подсистемы ролей и уведомлений

В текущей реализации уведомления о новых заявках, необходимости уточнения информации и завершении работ автоматически направляются всем пользователям с ролью **Manager**. Такой подход подходит для небольших организаций и позволяет любому менеджеру оперативно принять заявку в работу.

Архитектура системы предусматривает дальнейшее развитие без изменения общей структуры проекта.

Возможные направления развития:

- закрепление персонального менеджера за каждой заявкой;
- автоматическое распределение заявок между менеджерами;
- настройка персональных правил уведомлений;
- распределение заявок по подразделениям;
- поддержка нескольких групп специалистов;
- уведомления через Telegram и корпоративные мессенджеры;
- HTML-шаблоны писем с фирменным оформлением;
- добавление прямых ссылок на карточку заявки в уведомлениях.

# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

### Текущий этап разработки:
#### feature/web-statistics

В ветке реализована страница статистики заявок для веб-интерфейса HelpDesk System.
Статистика отображается в удобном виде и использует общую сервисную логику, которая также применяется REST API.

#### Реализовано

#### Backend

- вынесена логика формирования статистики в сервис `get_ticket_statistics()`;
- исключено дублирование кода между API и веб-интерфейсом;
- API продолжает использовать сервисный слой.

#### Web-интерфейс

Добавлена страница статистики **(statistics)**:

На странице отображаются:

- общее количество заявок;
- количество открытых заявок;
- количество закрытых заявок;
- количество критических заявок;
- статистика по статусам;
- статистика по приоритетам;
- статистика по категориям.

#### Особенности отображения

- статусы отображаются в логическом порядке;
- отображаются все статусы, включая отсутствующие;
- приоритеты отображаются по степени важности;
- категории выводятся автоматически из базы данных;
- используются русские названия статусов, приоритетов и категорий.

#### Разграничение доступа

Доступ к странице статистики имеют:

- руководитель (`manager`);
- специалист поддержки (`support`).

Обычный пользователь (`employee`) получает ошибку **403 Forbidden**.

Неавторизованный пользователь перенаправляется на страницу входа.

#### Тестирование

Добавлены тесты, проверяющие:

- доступ неавторизованного пользователя;
- ограничение доступа для `employee`;
- доступ для `support`;
- доступ для `manager`;
- корректную передачу статистики в шаблон.

Все тесты проходят успешно.

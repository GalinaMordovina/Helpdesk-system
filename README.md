# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

### Текущий этап разработки:
##### feature/statistics

#### Цель

Реализация аналитического модуля для получения статистики по заявкам технической поддержки.

#### Выполненные задачи

* создано приложение `statistics_app`;
* реализован endpoint `/api/statistics/`;
* выполнен подсчёт общего количества заявок;
* реализован подсчёт открытых заявок;
* реализован подсчёт закрытых заявок;
* реализован подсчёт критических заявок;
* реализована группировка заявок по статусам;
* реализована группировка заявок по приоритетам;
* реализована группировка заявок по категориям;
* добавлена документация endpoint через Swagger;
* выполнено тестирование через Postman.

#### Результат

В системе реализован аналитический модуль, позволяющий получать ключевые показатели работы службы технической поддержки. Пользователь может просматривать общее количество заявок, количество открытых и закрытых заявок, число критических инцидентов, а также распределение заявок по статусам, приоритетам и категориям.

# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

### Текущий этап разработки:
##### feature/tests

#### Цель

Добавление автоматического тестирования backend-приложения с использованием pytest и pytest-django.

#### Реализовано

#### Настройка инфраструктуры тестирования

- настроен pytest;
- настроен pytest-django;
- добавлен pytest-cov;
- создан файл `pytest.ini`;
- реализованы общие фикстуры (`conftest.py`) для пользователей, заявок и API-клиента.

#### Тестирование моделей

Проверены модели:

- User;
- Ticket;
- Comment.

Проверено:

- создание объектов;
- значения по умолчанию;
- строковые представления моделей;
- связи между моделями.

#### Тестирование REST API

Проверены:

- получение списка заявок;
- создание заявок;
- получение списка комментариев;
- создание, изменение и удаление комментариев.

#### JWT-аутентификация

Проверено:

- получение JWT access и refresh токенов;
- обновление access-токена;
- обработка неверных учетных данных.

#### Права доступа

Проверено:

- запрет доступа без авторизации;
- доступ для сотрудников;
- доступ для специалистов;
- доступ для менеджеров.

#### Поиск, фильтрация и сортировка

Проверены:

- фильтрация по статусу;
- фильтрация по нескольким статусам;
- фильтрация по категории;
- фильтрация по приоритету;
- поиск по теме заявки;
- сортировка результатов.

#### Валидация данных

Проверены сценарии:

- создание заявки без обязательных полей;
- использование некорректной категории;
- корректная обработка ошибок сериализатора.

#### Статистика

Проверен аналитический endpoint:

- общее количество заявок;
- открытые заявки;
- закрытые заявки;
- критические заявки;
- распределение по статусам, приоритетам и категориям.

#### Email-уведомления

Проверена работа сервиса уведомлений с использованием mock-объектов без отправки реальных писем.

Общее покрытие проекта составило **97%**, включая модели, API, JWT-аутентификацию, права доступа, поиск, фильтрацию, статистику и сервис уведомлений.

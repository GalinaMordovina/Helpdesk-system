# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей

- создание заявок;

### Текущий этап разработки:
#### feature/ticket-update-form

Исправлена форма создания и редактирования заявок с учётом роли пользователя.

### Редактирование статуса заявки


При создании новой заявки пользователь указывает:

- тему;
- описание;
- категорию;
- приоритет.

Статус новой заявки автоматически устанавливается в значение «Новая».

При редактировании заявки права распределяются следующим образом:

- сотрудник может изменять тему, описание, категорию и приоритет;
- сотрудник видит текущий статус заявки;
- сотрудник может оставить текущий статус или перевести заявку в статус «Ожидает уточнения»;
- сотрудник не может назначать исполнителя и устанавливать другие статусы;
- специалист и менеджер могут изменять все данные заявки, статус и назначенного исполнителя.

Ограничение доступных сотруднику статусов реализовано на уровне формы и проверяется на сервере. Ручная передача запрещённого статуса через POST-запрос не изменяет заявку.

Исправлено повторное отображение поля «Приоритет» в форме редактирования. Вместо продублированного поля корректно отображается поле «Статус».

При фактическом изменении статуса через веб-интерфейс вызывается сервис email-уведомлений. При переводе заявки в статус «Ожидает уточнения» уведомление отправляется менеджерам.

### Разграничение доступа к заявкам

Добавлено ограничение доступа к заявкам в веб-интерфейсе:

| Роль | Доступные заявки |
|------|------------------|
| Сотрудник | созданные им или назначенные ему |
| Специалист | все заявки |
| Менеджер | все заявки |

Ограничение применяется к:

- списку заявок;
- просмотру карточки заявки;
- редактированию заявки;
- удалению заявки.

Если сотрудник пытается открыть недоступную ему заявку по прямой ссылке, система возвращает ответ `404 Not Found`.

Поиск, фильтрация и сортировка выполняются только среди заявок, доступных текущему пользователю.

### Страница сотрудников

Обновлено отображение таблицы сотрудников:

- убрана цветовая подсветка количества заявок;
- количество активных и всех назначенных заявок отображается обычным текстом;
- статус пользователя отображается как «Активен» или «Неактивен» (для сотрудников, что выходят на больничный или отпуск);
- сохранён деловой и единообразный стиль веб-интерфейса.

### Демонстрационные данные

Добавлены тестовые пользователи с ролями специалистов и сотрудников, а также демонстрационные заявки и комментарии для проверки работы системы.

Пароли тестовых пользователей установлены через метод Django `set_password()`, обеспечивающий корректное хеширование паролей.

### Тестирование

Обновлены тесты с учётом новой логики:

- сотрудник видит ограниченный список статусов;
- сотрудник может установить статус «Ожидает уточнения»;
- сотрудник не может установить статус «Закрыта»;
- сотрудник получает доступ только к созданным им или назначенным ему заявкам;
- сохранены проверки редактирования заявок и ролевых ограничений.

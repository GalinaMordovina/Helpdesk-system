# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

### Текущий этап разработки:
##### feature/search-and-filters

####  Цель

Реализация поиска, фильтрации и сортировки заявок технической поддержки.

#### Выполненные задачи

* подключён `django-filter`;
* реализован поиск заявок по теме и описанию;
* реализована фильтрация по статусу;
* реализована фильтрация по нескольким статусам одновременно;
* реализована фильтрация по приоритету;
* реализована фильтрация по нескольким приоритетам;
* реализована фильтрация по категории;
* реализована фильтрация по автору заявки;
* реализована фильтрация по исполнителю;
* реализована фильтрация по диапазону дат создания;
* реализована фильтрация по диапазону дат обновления;
* реализована сортировка по дате создания, дате обновления, статусу и приоритету;
* добавлено описание параметров поиска и фильтрации в Swagger;
* выполнена проверка работы через Postman.

#### Результат

API заявок поддерживает поиск, фильтрацию и сортировку. Пользователь может быстро находить нужные заявки по ключевым словам, статусам, приоритетам, категориям, исполнителям и диапазону дат.

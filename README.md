# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

#### Технологический стек

- Django
- Django REST Framework
- PostgreSQL

### Текущий этап разработки:
#### feature/web-navigation

В рамках данной ветки был расширен веб-интерфейс системы HelpDesk.

#### Добавлено:
- реализована ролевая навигация на главной странице;
- карточка «Создание заявок» открывает страницу создания новой заявки;
- карточка «Работа специалистов»:
  - для сотрудников и специалистов открывает список заявок;
  - для менеджера открывает страницу сотрудников;
- карточка «Контроль и статистика» открывает страницу статистики (доступна только специалисту и менеджеру);
- создана страница «Сотрудники»;
- отображается список пользователей системы;
- отображается количество активных и всех назначенных заявок;
- пользователи отсортированы по ролям:
  - менеджеры;
  - специалисты;
  - сотрудники;
- страница сотрудников доступна только пользователю с ролью manager;
- обновлено боковое меню с учетом ролей пользователей;
- реализована подсветка активного раздела меню;
- отображение имени пользователя в верхней панели.

- навигация для всех ролей пользователей;

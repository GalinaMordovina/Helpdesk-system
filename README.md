# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

#### Технологический стек
- Backend

- Django
- Django REST Framework
- PostgreSQL

### Текущий этап разработки:
##### feature/api-documentation

#### Цель

Улучшение и завершение OpenAPI-документации проекта.

#### Реализовано

- улучшено описание API;
- настроены описания разделов Swagger (tags);
- добавлены описания JWT-аутентификации;
- реализованы собственные представления для получения и обновления JWT-токенов;
- оформлена документация endpoint текущего пользователя;
- добавлены сериализаторы ответов для APIView;
- улучшена документация аналитического endpoint статистики;
- устранены предупреждения drf-spectacular при генерации схемы OpenAPI.

#### Результат

Swagger UI и ReDoc полностью описывают API проекта и не содержат предупреждений при генерации OpenAPI-схемы.

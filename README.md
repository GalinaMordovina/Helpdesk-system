# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

#### Технологический стек
- Backend
- Python 3.12
- Django
- Django REST Framework
- PostgreSQL

#### Структура веток

##### Основные ветки
- main - стабильная версия проекта;
- develop - основная ветка разработки.
- feature-ветки (каждая новая функциональность реализуется в отдельной ветке):
  #### Backend
  - feature/project-setup - настройка Django-проекта, PostgreSQL, переменных окружения и GitHub;
  - feature/users-app - система пользователей и ролей;
  - feature/tickets-app - заявки технической поддержки;
  - feature/comments-app - комментарии к заявкам;
  - feature/authentication - JWT-аутентификация и endpoint текущего пользователя;
  - feature/api-setup - serializers, viewsets, routers и REST API;
  - feature/search-and-filters - поиск и фильтрация заявок;
  - feature/statistics - статистика и аналитика по заявкам;
  - feature/email-notifications - email-уведомления;
  - feature/roles-refactor - уточнение ролей пользователей; employee, manager, support;
  - feature/admin-panel - расширение административной панели;
  - feature/api-documentation - улучшение и завершение OpenAPI-документации проекта;
  - feature/tests - тесты.
 
  #### Web-интерфейс:

  - feature/web-layout - базовый интерфейс и шаблоны;
  - feature/web-auth - страницы входа и регистрации;
  - feature/web-tickets
  - feature/web-comments
  - feature/web-dashboard

  #### Финализация:

  - feature/docker-deployment

#### Что реализовано

#### Добавленные возможности

- просмотр списка заявок;

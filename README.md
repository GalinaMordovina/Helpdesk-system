# HelpDesk System
## Описание проекта

HelpDesk System - информационная система управления заявками технической поддержки, разработанная в рамках выпускной квалификационной работы.

Система предназначена для автоматизации процесса регистрации, обработки и контроля заявок пользователей, а также для анализа работы службы технической поддержки.

## Цель проекта

Разработка веб-приложения для централизованного управления заявками технической поддержки предприятия.

## Основные возможности
- регистрация и авторизация пользователей; 
- создание заявок; 
- просмотр списка заявок; 
- изменение статусов заявок; 
- назначение исполнителей; 
- добавление комментариев; 
- поиск и фильтрация заявок; 
- просмотр статистики; 
- формирование отчетов.

### Роли пользователей
#### Пользователь:
- создание заявок;
- просмотр собственных заявок;
- добавление комментариев.

#### Специалист технической поддержки:
- обработка назначенных заявок;
- изменение статусов;
- добавление комментариев;
- фиксация результатов выполнения.

#### Администратор
- управление пользователями;
- просмотр всех заявок;
- назначение исполнителей;
- просмотр статистики.

#### Технологический стек
- Backend
- Python 3.12
- Django
- Django REST Framework
- PostgreSQL

### Текущий этап разработки:
##### feature/users-app

#### Цель

Реализация системы пользователей для информационной системы управления заявками технической поддержки.

#### Выполненные задачи

* создано приложение `users`;
* реализована кастомная модель пользователя на основе `AbstractUser`;
* добавлено поле роли пользователя (`role`);
* настроена кастомная модель через `AUTH_USER_MODEL`;
* выполнены миграции базы данных;
* создан суперпользователь;
* настроена административная панель Django;
* реализован служебный эндпоинт проверки работоспособности API (`health check`).

#### Роли пользователей

| Роль    | Описание                         |
| ------- | -------------------------------- |
| user    | Пользователь системы             |
| support | Специалист технической поддержки |
| admin   | Администратор системы            |

#### Результат

Подготовлена базовая система управления пользователями, которая будет использоваться во всех последующих модулях проекта.
